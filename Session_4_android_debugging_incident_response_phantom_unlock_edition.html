3. nftables logging, tcpdump and NFLOG

Kernel log form

tcp dport 4040 \
  limit rate 5/second \
  log prefix "IR_DENY " \
  level warning \
  drop

The log statement does not terminate rule evaluation. A verdict such as drop must follow when the policy requires a drop.

NFLOG form

limit rate 5/second \
  log group 100 \
  prefix "IR_DENY " \
  snaplen 128 \
  drop

The kernel sends matching packet metadata/payload samples to an NFLOG netlink group. A userspace consumer such as ulogd2 or a compatible capture tool subscribes to that group.

Capture placement matters: a packet capture proves observation at a capture point. It does not by itself prove the final nftables verdict. Correlate PCAP timestamps with rule counters or NFLOG/kernel-log records.

4. DLT logs and SOME/IP IDS alerts

DLT mental model

Diagnostic Log and Trace gives automotive applications structured context. Common fields include ECU identity, application ID (APID), context ID (CTID), severity and message payload.

DLT complements packet evidence: a packet may show service 0x1234; DLT can explain that the gateway rejected an unauthorized remote-unlock request.

SOME/IP IDS mental model

The IDS parses the 16-byte SOME/IP header and applies service-aware policy: source, service ID, method/event ID, client/session request ID, protocol/interface version, message type, return code and declared length.

The lab uses UDP port 30490 for a controlled exercise. Production service ports are configuration-specific.

5. Firewall rule auditing and policy testing

Static checks

  • nft -c -f ruleset.nft checks syntax without applying it.
  • JSON export supports automated review.
  • Comments, handles and named sets improve traceability.
  • Look for shadowed rules, broad accepts and unbounded logging.

Dynamic checks

  • Positive tests prove approved traffic still works.
  • Negative tests prove prohibited traffic is blocked.
  • Counters prove the intended rule matched.
  • PCAP/NFLOG evidence proves observation and logging.

A systematic, risk-based organizational approach defining processes, responsibilities and governance for vehicle cybersecurity.

Vehicle type

⏱️ Clock trap: a perfect event order can still be wrong when ECUs have different clock offsets. Preserve original timestamps and document every conversion.

Normalize time

Record UTC offset, NTP/PTP status, boot-relative clocks, drift and collection delay. Never silently rewrite original evidence.

Correlate identifiers

Source IP, ECU, APID/CTID, service/method, client/session, rule handle, vehicle ID and process identity connect records.

Separate fact from inference

#!/usr/bin/env python3
from __future__ import annotations
import argparse, datetime as dt, ipaddress, json, pathlib, socket, struct

PCAP_MAGIC = 0xA1B2C3D4
BASE_TIME = dt.datetime(2026, 8, 2, 9, 0, 0, tzinfo=dt.timezone.utc)

def iso(offset_ms: int) -> str:
    return (BASE_TIME + dt.timedelta(milliseconds=offset_ms)).isoformat(timespec="milliseconds").replace("+00:00", "Z")

def checksum(data: bytes) -> int:
    if len(data) % 2: data += b"\x00"
    total = sum(struct.unpack("!%dH" % (len(data)//2), data))
    total = (total >> 16) + (total & 0xFFFF)
    total += total >> 16
    return (~total) & 0xFFFF

def someip(service: int, method: int, client: int, session: int, iface: int, payload: bytes, *, length_override: int | None = None) -> bytes:
    message_id = (service << 16) | method
    request_id = (client << 16) | session
    length = 8 + len(payload) if length_override is None else length_override
    return struct.pack("!III4B", message_id, length, request_id, 1, iface, 0x00, 0x00) + payload

def udp_frame(src: str, dst: str, sport: int, dport: int, payload: bytes, ident: int) -> bytes:
    src_b = ipaddress.IPv4Address(src).packed; dst_b = ipaddress.IPv4Address(dst).packed
    udp_len = 8 + len(payload)
    pseudo = src_b + dst_b + struct.pack("!BBH", 0, socket.IPPROTO_UDP, udp_len)
    udp_hdr = struct.pack("!HHHH", sport, dport, udp_len, 0)
    udp_sum = checksum(pseudo + udp_hdr + payload)
    udp_hdr = struct.pack("!HHHH", sport, dport, udp_len, udp_sum)
    total_len = 20 + udp_len
    ip_hdr = struct.pack("!BBHHHBBH4s4s", 0x45, 0, total_len, ident, 0, 64, socket.IPPROTO_UDP, 0, src_b, dst_b)
    ip_sum = checksum(ip_hdr)
    ip_hdr = struct.pack("!BBHHHBBH4s4s", 0x45, 0, total_len, ident, 0, 64, socket.IPPROTO_UDP, ip_sum, src_b, dst_b)
    eth = b"\x02\x00\x00\x00\x00\x20" + b"\x02\x00\x00\x00\x00\x10" + struct.pack("!H", 0x0800)
    return eth + ip_hdr + udp_hdr + payload

def write_pcap(path: pathlib.Path, packets: list[tuple[int, bytes]]) -> None:
    with path.open("wb") as f:
        f.write(struct.pack("<IHHIIII", PCAP_MAGIC, 2, 4, 0, 0, 65535, 1))

            sec = int(t.timestamp()); usec = t.microsecond
            f.write(struct.pack("<IIII", sec, usec, len(packet), len(packet)))
            f.write(packet)

def main() -> None:

    logs.mkdir(parents=True, exist_ok=True); pcaps.mkdir(parents=True, exist_ok=True)
    firewall = [

#!/usr/bin/env python3
from __future__ import annotations
import argparse, collections, datetime as dt, ipaddress, json, pathlib, struct

def iso(sec:int,usec:int)->str:
    return dt.datetime.fromtimestamp(sec+usec/1_000_000,dt.timezone.utc).isoformat(timespec="milliseconds").replace("+00:00","Z")

def parse_pcap(path:pathlib.Path):
    data=path.read_bytes(); off=24
    if len(data)<24 or data[:4] not in (b"\xd4\xc3\xb2\xa1",b"\xa1\xb2\xc3\xd4"): raise ValueError("not a classic pcap")
    little=data[:4]==b"\xd4\xc3\xb2\xa1"
    endian="<" if little else ">"
    while off+16<=len(data):
        sec,usec,cap,orig=struct.unpack_from(endian+"IIII",data,off);off+=16
        frame=data[off:off+cap];off+=cap
        yield sec,usec,frame

def main():
    ap=argparse.ArgumentParser();ap.add_argument("--base",required=True);a=ap.parse_args();base=pathlib.Path(a.base)
    policy=json.loads((base/"config/policy.json").read_text()); cfg=policy["someip"]; trusted=set(policy["trusted_someip_sources"])
    alerts=[]; seen={}; rates=collections.defaultdict(list); parsed=0; normal=0
    for sec,usec,frame in parse_pcap(base/"pcaps/someip_incident.pcap"):
        if len(frame)<42 or frame[12:14]!=b"\x08\x00": continue
        ihl=(frame[14]&0x0F)*4; proto=frame[23]
        if proto!=17: continue
        src=str(ipaddress.IPv4Address(frame[26:30])); udp=14+ihl; dport=struct.unpack_from("!H",frame,udp+2)[0]
        if dport!=30490: continue
        payload=frame[udp+8:];
        if len(payload)<16: continue
        parsed+=1; mid,length,rid,pv,iface,mtype,rc=struct.unpack_from("!III4B",payload,0)
        service=mid>>16; method=mid&0xFFFF; client=rid>>16; session=rid&0xFFFF; ts=sec+usec/1_000_000
        def alert(kind,severity,detail): alerts.append({"ts":iso(sec,usec),"source":"SOMEIP_IDS","kind":kind,"severity":severity,"src":src,"service":service,"method":method,"session":session,"detail":detail})
        if src not in trusted: alert("UNAUTHORIZED_SOURCE","high","source is outside trusted SOME/IP allowlist")
        if service!=cfg["service_id"] or method not in cfg["allowed_methods"]: alert("UNKNOWN_SERVICE_METHOD","medium","service or method is not allowed by policy")
        key=(src,client,session,service,method)
        if key in seen and ts-seen[key] <=5: alert("REPLAY","high","request identifier repeated inside replay window")
        seen[key]=ts
        if iface!=cfg["interface_version"]: alert("INTERFACE_VERSION","medium",f"expected {cfg['interface_version']} got {iface}")
        actual_length=len(payload)-8
        if length!=actual_length: alert("INVALID_LENGTH","high",f"declared {length} actual {actual_length}")
        rates[src]=[x for x in rates[src] if ts-x<1.0]; rates[src].append(ts)
        if len(rates[src])==cfg["max_requests_per_second"]+1: alert("RATE_EXCEEDED","high","per-source request threshold exceeded")
        if src in trusted and method in cfg["allowed_methods"] and iface==cfg["interface_version"] and length==actual_length: normal+=1
    out=base/"logs/ids_alerts.jsonl"
    with out.open("w") as f:
        for row in alerts:f.write(json.dumps(row,sort_keys=True)+"\n")
    summary={"parsed":parsed,"normal":normal,"alerts":len(alerts),"kinds":sorted(set(x["kind"] for x in alerts))}
    (base/"reports/ids_summary.json").write_text(json.dumps(summary,indent=2)+"\n")
    print(f"[PASS] SOME/IP IDS parsed={parsed} alerts={len(alerts)} kinds={','.join(summary['kinds'])}")
if __name__=="__main__":main()

Android 17 correction: do not treat dumpsys netd as a required command. In modern Android, TrafficController/BPF diagnostics are exposed through dumpsys connectivity trafficcontroller. The netd native daemon may still be running even when there is no dumpable service named netd.

Troubleshooting — “Can't find service: netd”

This is not evidence that networking is broken. It means the current build does not expose a dumpable Binder service using the literal name netd.

# 1. Discover what dumpsys can actually dump.
"$ADB" -s "$SERIAL" shell dumpsys -l |
  grep -E 'connectivity|netstats|netpolicy|network|netd'

# 2. Android 13+ / Android 17 TrafficController dump.
"$ADB" -s "$SERIAL" \
  shell dumpsys connectivity trafficcontroller |
  head -n 120

# 3. Confirm the native daemon separately.
"$ADB" -s "$SERIAL" shell '
  pidof netd ||
    ps -A | grep -E "[[:space:]]netd([[:space:]]|$)"
'

# 4. Inspect BPF runtime state.
"$ADB" -s "$SERIAL" shell '
  mount | grep -E " type bpf |/sys/fs/bpf"
  ls -la /sys/fs/bpf | head -n 60
'

Expected interpretation: connectivity trafficcontroller should be preferred on Android 17. If it is absent too, record it as a capability difference and continue with dumpsys connectivity, netstats, netpolicy, process evidence and /sys/fs/bpf.

Evidence discipline: record acquisition time, host/device clock, Android build fingerprint, ADB serial, commands, collector identity and hashes. Keep originals read-only and perform analysis on copies.
